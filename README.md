# AI Coding Tools Guide 🚀

A modern, professional, fully responsive interactive learning platform that teaches developers how to use AI-assisted coding tools (Antigravity, GitHub Copilot, Cursor, Claude, ChatGPT) for software engineering.

## 🌟 Features Included

1. **Frontier AI Coding Tools Index**
   - In-depth, factual profiles for **Antigravity**, **GitHub Copilot**, **Cursor**, **Claude**, and **ChatGPT**.
   - Comprehensive breakdowns of setup, workflow, advantages, limitations, and example prompts.
   - Side-by-side comparison matrix covering agentic execution, terminal commands, multi-file diffs, and context limits.

2. **Antigravity 8-Step Coding Tutorial**
   - **Step 1:** Create/Open a Project
   - **Step 2:** Explain Your Goal
   - **Step 3:** Ask AI to Plan (Requirement analysis & implementation blueprint)
   - **Step 4:** Generate the Project (Components, Pages, API routes, DB models, Auth, Styling, Utilities)
   - **Step 5:** Review the Code (Interactive 6-point verification checklist)
   - **Step 6:** Debug with Precision (Root-cause error diagnosis)
   - **Step 7:** Test Thoroughly (Unit, Integration, API, Edge-case tests)
   - **Step 8:** Refactor for Longevity (Clean architecture & zero behavioral regression)

3. **Prompt Engineering Formula & Interactive Generator**
   - Complete breakdown of the 6-part prompt formula:  
     `Context + Goal + Technology + Requirements + Constraints + Expected Output`
   - Bad prompt vs. Good prompt comparison.
   - **Interactive Prompt Builder** with customizable fields, one-click presets, dynamic live output, and copy-to-clipboard functionality.

4. **Production Prompt Examples Library**
   - 50+ categorized prompts covering:
     - Website Development
     - Debugging
     - Refactoring
     - API Development
     - Database Design
     - Testing & Edge Cases
     - Code Review & Security Audits
   - Real-time search filter and category tab switching.
   - Copy button with instant toast notification.

5. **8-Stage AI Development Workflow**
   - `Idea → Requirements → AI Planning → Code Generation → Review → Testing → Debugging → Deployment`
   - Detailed division of responsibilities: Developer Action vs. AI Assistance vs. Verification Gates.

6. **Real Project Case Study: Instagram Clone**
   - Full-stack blueprint with React, Node.js, Express, MongoDB, JWT auth, S3 media uploads, and AI Content Moderation.
   - Exact copyable prompts and expected architecture outputs for every phase.

7. **10 AI Coding Best Practices & Security Warning**
   - Highlighted security notice: *“AI-generated code can contain bugs and security vulnerabilities. Always review and test code before deploying it.”*
   - 10 actionable rule cards with concrete DOs and DON'Ts.

8. **Interactive FAQ Accordion**
   - Expandable, searchable accordion addressing all 10 core questions about AI development, career impact, debugging, and safety.

9. **Theme & UI**
   - Dark developer theme with deep navy/slate backgrounds (`#080B11`), glassmorphism cards, and purple/blue gradient accents.
   - Dark/Light mode switcher with persistence.
   - Mobile responsive hamburger menu drawer.
   - Floating toast notification system.

## 🚀 How to Run Locally

### 1. Prerequisites
Ensure you have **Node.js (v18+)** installed.

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or the port indicated in your terminal).

### 4. Build for Production
```bash
npm run build
```

### 5. Preview Production Build
```bash
npm run preview
```
